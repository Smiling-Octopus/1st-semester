# Windows Information Gathering
Windows OS System Information Gathering

[ 실행 과정 ]

(1) pip install pynput
* (터미널(명령 프롬프트)에서 실행)

(2) 키로거 파이썬 코드 작성

(3) pip install pyinstaller		# 파이썬 코드 exe 파일 변환 라이브러리
* (터미널(명령 프롬프트)에서 실행)

(4) pyinstaller --onefile '.\Information Gathering.py'		# 파이썬 코드 exe 파일 변환 명령어
* (터미널(명령 프롬프트)에서 실행)

(5) Information Gathering.exe 실행
